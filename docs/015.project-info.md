# 015 — 项目信息（Project Info）

> 项目事实卡：定位 / 技术栈 / 骨架 / 构建与运行 / 当前能力。版本与键的事实来源是父 `pom.xml` 与 `application.yml`。

## 011.定位

`klsjnh-java17-lowcode011` —— Java 17 纯血 DDD **低代码产品**工程（Maven 多模块），**依赖框架底座** `com.klsjnh:java17-framework011:1.0.0`（common / domain / application / infrastructure / web 构件）。承载低代码域：元数据引擎 · 设计/发布/运行时/开放 API · 模板 · 多入口建模（含 AI 一句话）。对外契约（响应信封 / 状态码 / 路由风格）见 [013.api-contract](013.api-contract.md)。

## 015.Maven 骨架

```
com.klsjnh:java17-lowcode011:1.0.0（父 POM，packaging=pom）
├── java17-lowcode011-domain          低代码域（聚合 / 契约 / 端口 / 策略）——禁框架
├── java17-lowcode011-application     用例编排 + @Transactional
├── java17-lowcode011-infrastructure  持久化（july_metadata* / july_business_modeling）+ DDL/方言 + 模板编解码 + 探针
├── java17-lowcode011-web             Controller / VO / 模板文件流
└── java17-lowcode011-app011          唯一 main + 配置 + profile
```

- 包名 `com.klsjnh.lowcode011.*`；端点前缀 `/klsjnh/lowcode011/**`（开放 API `/klsjnh/open/**`）。

## 017.构建与运行

```bash
./script011.sh gate      # 门禁：编码规范（正则 + AST）+ mvn 离线编译
./script011.sh build011  # mvn clean package install
./script011.sh dev013    # 杀进程 + 重新编译 + 启动（11170）
java -jar java17-lowcode011-app011/target/java17-lowcode011-app011-1.0.0.jar   # 11170 端口
```

- 端口 **11170**；接口文档 `http://127.0.0.1:11170/doc.html`（分组：低代码011 + 框架的 系统管理011 / 数据源011 / 存储中心 / AI模型接入011）。
- 数据库：`klsjnh_lowcode011`（平台基表 + 低代码表）；DDL 见 [sql/](sql/)。
- 前置：先 `mvn install` 框架构件；Node 18+（门禁 AST）。

## 019.当前能力（截至 2026-09-19）

- 元数据引擎：一主三子 CRUD；`MetadataContent` 契约 + `ObjectTablePolicy/Gateway`（042）。
- 设计器 / 发布：`listModels/load/save/previewDdl`、`publish`（CREATE/ALTER + 快照/版本）。
- 数据同步：`importDataFromSql/importStatus`（分页 + 按 `businessField` upsert 幂等）。
- 运行时：`publishMenu/listRuntimeMenus` + `runtime/v1` JWT 动态 CRUD（含元数据校验）。
- 开放 API：`openApiConfig/saveOpenApiConfig/rotateApiKey` + `/klsjnh/open/v1`（`X-Api-Key`）。
- 模板多格式：JSON / CSV / Markdown 导出导入（XLSX 占位）；`TemplateCodec` 端口。
- 多入口 intake：`intake/v1/{review,create}`（kind=sql/template/copy/modeling/ai；**AI 一句话**）。
- 业务建模：探针推断 + 执行/分页 SQL + 交接产物（`july_business_modeling`）。
- 目标库方言：`DialectResolverPort` 按 `DatabaseType011` 自动路由（MySQL 实现；Oracle/SQLServer 占位，052）。
